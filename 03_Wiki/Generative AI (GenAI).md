# Generative AI (GenAI)

IA generativa cria conteúdo novo — texto, imagens, áudio, vídeo ou código — aprendendo padrões a partir de grandes datasets. Diferente da IA tradicional (que analisa ou classifica dados), a GenAI produz saídas originais. Exemplos: ChatGPT, Copilot, Gemini, Claude.

## ML vs Deep Learning vs GenAI

| Aspecto | Machine Learning | Deep Learning | Generative AI |
|---|---|---|---|
| Definição | Aprende padrões para prever | ML baseado em redes neurais para padrões complexos | Cria conteúdo novo (texto, imagens) |
| Necessidade de Dados | Datasets pequenos a médios | Grandes volumes de dados | Datasets muito grandes |
| Complexidade do Modelo | Baixa a média | Alta | Muito alta |
| Necessidade Computacional | Baixa | Alta (GPU) | Muito alta (GPU/TPU) |

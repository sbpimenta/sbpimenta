# Tipos de Prompts

Um **prompt** é a instrução ou entrada fornecida a um LLM para obter uma resposta. Existem diferentes estilos de prompt, usados tanto para uso legítimo quanto como base para ataques de [[Prompt Injection]] e [[Técnicas de Jailbreak em LLMs]]:

- **Zero-shot** — pede a tarefa diretamente, sem exemplos.
- **Few-shot** — fornece alguns exemplos antes de pedir a tarefa.
- **Role-based (baseado em persona)** — instrui o modelo a assumir um papel/persona específico.
- **Contextual** — inclui contexto adicional relevante junto ao pedido.
- **Chain-of-Thought** — pede ao modelo que raciocine passo a passo antes de responder.

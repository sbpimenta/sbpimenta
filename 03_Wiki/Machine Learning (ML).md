# Machine Learning (ML)

**Machine Learning (ML)** é um ramo da Inteligência Artificial que permite que sistemas aprendam padrões a partir de dados, sem programação explícita, e melhorem seu desempenho à medida que são treinados com mais dados.

## Técnicas de Machine Learning
- **Aprendizado Supervisionado** — usa dados rotulados, onde a saída correta já é conhecida.
- **Aprendizado Não Supervisionado** — trabalha com dados não rotulados para encontrar padrões ocultos.
- **Aprendizado por Reforço** — o modelo aprende tomando ações e recebendo recompensas ou penalidades.

## As 7 Etapas de Treinamento de um Modelo de ML
1. Coleta de dados (Gathering Data)
2. Preparação dos dados (Preparing that Data)
3. Escolha do modelo (Choosing a Model)
4. Treinamento (Training)
5. Avaliação (Evaluation)
6. Ajuste de hiperparâmetros (Hyperparameter Tuning)
7. Predição (Prediction)

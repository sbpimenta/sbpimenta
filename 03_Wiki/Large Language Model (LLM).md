# Large Language Model (LLM)

Modelo treinado em grandes volumes de dados textuais para compreender e gerar linguagem humana. Usa arquitetura Transformer (deep learning) para prever a próxima palavra com base no contexto. Em cibersegurança, LLMs auxiliam na análise de ameaças e automatizam tarefas como escrita de regras de detecção e scripts de resposta.

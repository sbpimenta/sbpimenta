# Dados de Treinamento (Training Data)

Conjunto de dados usado para treinar modelos de IA e LLMs. É a partir desses dados que os modelos aprendem padrões, relações e comportamentos. Podem incluir texto, imagens, áudio, vídeo e dados de sensores.

A integridade desses dados é crítica: se forem manipulados, o modelo aprende comportamentos incorretos — ver [[Data Poisoning]].

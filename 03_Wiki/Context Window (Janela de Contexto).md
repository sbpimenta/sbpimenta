# Context Window (Janela de Contexto)

Número máximo de tokens que um LLM consegue ler, lembrar e usar de uma vez — funciona como a "memória de curto prazo" do modelo. Existe porque os mecanismos de atenção comparam cada token com todos os outros, o que exige grande poder computacional; por limitações de hardware e eficiência, o modelo não pode lembrar tokens ilimitados.

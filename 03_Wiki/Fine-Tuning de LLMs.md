# Fine-Tuning de LLMs

Processo de continuar o treinamento de um LLM pré-treinado usando dados customizados, para que ele se comporte de forma específica em uma tarefa. Usado para adaptar o modelo a conhecimento de domínio específico, melhorar precisão/consistência e impor um estilo ou formato de resposta específico.

Modelos distribuídos com fine-tuning malicioso (ou adapters LoRA comprometidos) são um vetor real de ataque — ver [[Backdoors em Modelos de IA]].
